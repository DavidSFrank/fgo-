# FGO 文字冒险档案库

这个仓库用于进行 **FGO（Fate/Grand Order）文字冒险游戏** 的长期记录与游玩。

## 目录说明

- `lore/world.md`：世界观与规则设定
- `lore/characters.md`：角色档案（主角、从者、NPC）
- `gameplay/current_session.md`：当前进行中的剧情与选择记录
- `saves/slot1.md`：存档位（可复制出更多存档）

## 使用方式

1. 先在 `lore/` 下完善设定与角色。
2. 每次游玩把剧情推进记录在 `gameplay/current_session.md`。
3. 关键节点同步到 `saves/slot1.md`，便于回档与分支游玩。
